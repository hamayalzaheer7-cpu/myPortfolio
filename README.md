# HAMAYAL. — Personal Portfolio Website

Personal portfolio of **Hamayal Zaheer**, MERN Stack Developer & BS Information Technology (7th Semester) student at Superior University.

## Tech Stack
- React.js (Vite)
- Bootstrap 5
- Lucide React Icons
- Custom Editorial CSS Architecture

## Run Locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Upload this repository to GitHub (`https://github.com/hamayalzaheer7-cpu`).
2. Import the repository on [vercel.com](https://vercel.com).
3. Click **Deploy** (Framework Preset: Vite).
